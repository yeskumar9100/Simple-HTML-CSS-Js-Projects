# Simple HTML-CSS-JS Projects

Welcome to my collection of beginner-friendly web development projects!  
Each folder in this repository contains a mini project made using **HTML**, **CSS**, and sometimes a bit of **JavaScript**.

I created these projects to practice and improve my frontend development skills.

---

## 📁 Projects Included

### `1-simple_webpage`
A basic static webpage with headings, paragraphs, images, and links. Perfect starting point for any HTML beginner.

### `2-centered-div`
A responsive div box centered both vertically and horizontally using Flexbox. Great for understanding layout techniques.

### `3_navigation_bar`
A horizontal navigation bar using HTML and CSS. Includes hover effects and layout styling.

### `4_form_design`
A styled form with input fields, labels, and buttons. Covers CSS form elements and user interface design basics.

### `5_horizontal_list`
Displays a horizontal list using CSS Flexbox. Demonstrates how to style and align list items side by side.
